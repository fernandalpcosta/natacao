Conectar ao GitHub

Para mudar o calendário daqui, a página precisa de um token do GitHub que só consegue disparar os fluxos deste repositório. Ele fica salvo só neste navegador.

  1. Abra GitHub → Fine-grained token.
  2. Em Repository access, escolha Only select repositories → natacao.
  3. Em Permissions: Actions: Read and write e Contents: Read-only.
  4. Gere, copie e cole abaixo.

Não use um token com mais permissões que isso. Para revogar, apague-o nas configurações do GitHub.
